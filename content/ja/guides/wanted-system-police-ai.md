GTA6 の指名手配システムは大幅に刷新され、警察はもう「どこからともなく現れ」ません。本記事では**公式確認済みの原則**と**リーク実機/試玩報道による詳細**を区別します。

## 公式確認済みの原則

Rockstar 共同責任者の Rob Nelson 氏は「指名手配システムは**誰かが犯罪を目撃するか、警報が発動しないと通報されない**」と確認——つまり誰にも見られなければ、犯罪が即座に警察を呼ぶとは限りません。

## 六つ星の復活（リーク実機による、公式発表ではない）

- 六つ星の指名手配は『GTA4』以降姿を消し、『GTA5』は五つ星のみ。リーク実機映像では GTA6 で六つ星が復活するとのこと。
- リーカーは映像が「100% 本物」と主張しますが、Take-Two は DMCA で削除を続けており、正確な仕組みは正式版に準じます。

## 作り直された警察AIと追跡

- **リアルな到着時間**：警察は署からの距離に応じて到着し、瞬間出現はしない。
- **持続的な識別**：警察は容疑者の外見・服装・ナンバーを記録。見られずに着替え/乗り換えができて初めて有効。
- **戦術的な包囲捜索**：犬・ヘリ・サーチライトで捜索範囲を設定し、隠れ場所へ一直線には向かわない。
- **星が増える前の警告**：警察はまず拡声器で呼びかけて警告する。

## 4種類の星アイコンの状態

| 星アイコン | 意味 |
|---|---|
| 塗りつぶし白星 | 警察が直接視認しており、積極的に追跡中 |
| 点滅する白星 | 視界が切れ、警察が最後の居場所を捜索中 |
| 赤星 | 警察は足取りを見失ったが、捜索中の「ホットゾーン」内にいる |
| 白抜き星 | 犯罪は通報済みだが、まだ容疑者として特定されていない |

六つ星時は「ホットゾーン」がマップ全体を覆うこともあります。

## 証拠アイコン（警察が把握する情報）

指名手配星の下に表示され、1つずつ消す必要があります：

- **ハンガー**：服装を特定された → 完全に着替える
- **人型**：顔/体格を記録された → 髪型を変えるか見た目を大きく変える
- **カメラ**：CCTV に映った → 監視カメラの多い場所を避ける
- **車のアイコン**：車両を追跡された → 車を捨てる
- **二人のアイコン**：Jason と Lucia が一緒に目撃された → 別行動をとる
- **武器アイコン**（一部試玩報道で言及、最終確認待ち）：武器を特定された

## 六つ星レベルの内訳

| 星 | 対応戦力 |
|---|---|
| 1つ星 | 地元パトロール：口頭警告、軽い罰金、定期検問 |
| 2つ星 | バイスシティ警察：積極追跡、PIT 停止、基本のバリケード |
| 3つ星 | 州警察＋航空支援：スパイクベルト、サーチライト追跡、包囲 |
| 4つ星 | SWAT：装甲車、突入、狙撃手 |
| 5つ星 | 連邦機関（FIB）：高速道路封鎖、重火器 |
| 6つ星 | 軍の投入：全市封鎖、重火器、強力な迎撃 |

## 逃走テクニック

- **視界を断つ**：路地、地下施設、荒野に隠れる。
- **見られずに乗り換え**：誰も見ていないうちに新しい車を盗む。
- **犯行前にマスクを着用**：顔の特定を避ける。
- **着替え＋髪型変更**：服装/身元の証拠を無効化。
- **別行動をとる**：「二人一緒」の手がかりを消す。
- **群衆に紛れる**：動く群衆や屋内に溶け込む。
